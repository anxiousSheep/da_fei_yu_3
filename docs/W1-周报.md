## 三、Electron 崩溃（历史，已绕开）

stock Electron（40/44/45）在本机启动即 0xC0000005 / 0x80000003 崩溃。曾一度归因 Nahimic 注入（确实在注入 `AudioDevProps2.dll`，是帮凶），但停用后崩溃依旧。最终根因：本机 stock Chromium 的 **GPU 虚拟化上下文创建失败**（`Failed to create shared context for virtualization`）。已逐一排除 Nahimic、GameViewer 虚拟显示器、Electron 版本、进程树、缓存、GPU/沙箱参数；仅 DeepSeek 自研改造版 Electron 能跑。这是机器级环境问题（双显卡 + 虚拟显示器组合），普通用户机器不受影响。系统改动（Nahimic/GameViewer）已全部还原。
